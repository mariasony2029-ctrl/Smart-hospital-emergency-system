# Smart Hospital Emergency Resource Management System

## Project Description
This is a Java-based mini-project designed to support hospital emergency resource management through a graphical user interface.

## Technologies Used
- Java
- Java Swing
- GitHub

## Features
- Graphical user interface using Java Swing.
- User-friendly desktop application.
- Demonstrates Java programming concepts in a hospital emergency management scenario.

## Requirements
- Java Development Kit (JDK)
- Java-compatible IDE or terminal

## How to Run
1. Download or clone this repository.
2. Open a terminal in the folder containing `SmartHospitalGUI.java`.
3. Compile the program:

   `javac SmartHospitalGUI.java`

4. Run the program:

   `java SmartHospitalGUI`

**Note:** If additional source files or libraries are required, include them before compiling.
